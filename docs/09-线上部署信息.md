## Railway 服务

- 项目：hotel-booking-system
- hotel-web：Vue 3 前端 + Nginx，负责静态资源和 /api 反向代理
- hotel-api：Spring Boot 3 后端
- MySQL：Railway 托管 MySQL，数据库名 railway
- 已初始化：8 个房型、20 间房、32 条评论、720 条库存记录

## 当前部署方式

线上版本由 Railway CLI 从本地项目上传构建并部署。
