# 公开点评数据说明

## 数据来源

- 来源站点：华住会公开酒店详情页
- 酒店页面：全季上海虹桥吴中路酒店
- 页面地址：https://m.huazhu.com/hotel/detail/2003362
- 页面公开信息：综合评分 4.8，公开评价数量 36877 条
- 本地整理日期：2026-09-22

## 处理原则

1. 只使用页面公开可见的点评信息。
2. 不保存会员昵称、手机号、账号 ID 或其他个人信息。
3. 评论展示统一使用会员等级或“匿名客户”。
4. 对较长评论进行匿名化摘要，去除个人姓名和无关纠纷信息。
5. 本数据仅用于课程项目展示，不作为商业数据源。

## 本地用途

评论数据写入 database/seed.sql 的 review 表，用于：

- 房型平均评分统计。
- 评论总数统计。
- 评论列表弹窗。
- 数据库聚合查询与前后端接口演示。
