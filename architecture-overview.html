2核心机制：按“夜”库存与并发防超卖

酒店客房按日期区间售卖，区别于普通电商“一件卖一次”。库存粒度为 房型 × 日期 × 可售间数。

下单在一个数据库事务内，对区间内每个日期执行条件更新；任一夜不满足则整单回滚。正确性以数据库行锁 + 条件判断为准，Redis 锁仅作热点前置兜底。
-- 条件扣减：仅当该夜剩余可售 ≥ 预订间数时才更新，受影响行数 0 即库存不足
UPDATE room_inventory
   SET booked_count = booked_count + #{qty}
 WHERE room_type_id = #{roomTypeId}
   AND inventory_date = #{date}
   AND total_count - booked_count >= #{qty};

-- 区间可售量取每夜最小值；库存行不齐直接判 0，避免漏判超卖
SELECT MIN(total_count - booked_count) FROM room_inventory
 WHERE room_type_id=? AND inventory_date >= ? AND inventory_date < ?;

3在线预订主流程（含事务与回滚）

半开区间 [入住日, 离店日) 计库存与计费，间夜数 = 离店 − 入住。

1
查询可用房型
逐夜计算最小可售量与 N 晚总价，未登录可访问；任一夜为 0 则置灰“不可订”。
2
提交订单
校验日期（离店>入住）、房型在售、联系人；按“房型+间数”提交。
✕ 任一夜可售 < 预订间数 → 返回 4002 库存不足，整单回滚，不产生订单与扣减。
3
事务内逐夜扣减库存
对每个房型、区间内每一夜执行条件 UPDATE（见第 2 节）。
▣ 同一事务：生成订单（待支付，15 分钟过期）+ 一行一间展开明细，锁定下单时单价。
4
限时支付（默认 15 分钟）
支付回调做幂等（第三方交易号唯一）。
✕ 超时未支付 → 定时任务置“已取消”并逐夜释放库存；重复回调不重复确认。
5
支付成功 → 已确认
订单 CONFIRMED，库存正式占用，记录支付流水。
6
前台排房并入住
校验同房型、房间空闲 VC、区间无冲突；回填房间、房间置 OC、订单 CHECKED_IN。
7
退房结账
订单 COMPLETED，房间转 VD 待清洁；清洁合格回 VC 可再次售卖。

5数据模型（ER 关系，MySQL 8.0）

采用逻辑外键 + 唯一索引 + 条件更新保证一致性；可售量不落冗余列。完整数据字典见 DBD。

user 用户
  • id PK
  • phone UQ
  • password_hash / salt
  • role / status
room_type 房型
  • id PK
  • code UQ
  • name / bed_type
  • base_price / amenities
room 物理房间
  • id PK
  • room_no UQ
  • room_type_id FK
  • status(VC/VD/OC/OOO)
room_inventory 每日库存
  • id PK
  • room_type_id FK
  • inventory_date
  • total / booked UQ(type,date)
reservation 订单主表
  • id PK
  • order_no UQ
  • user_id FK
  • check_in/out_date·nights
  • total_amount / status
reservation_item 订单明细
  • id PK
  • reservation_id FK
  • room_type_id FK
  • room_id（排房回填）FK
payment 支付流水
  • id PK
  • payment_no UQ
  • reservation_id FK
  • transaction_id UQ·幂等
review 评价·预留
  • reservation_id 一单一评
  • score(1-5) / content
room_rate 日历房价·预留
  • (room_type_id, rate_date) UQ
  • price（动态定价）
notification_log 通知·预留
  • type / channel / biz_no
  • status / send_time
user 1 — N reservation（一个会员多张订单）
room_type 1 — N room（房型拥有多间物理房）
room_type 1 — N room_inventory（每房型每天一条库存）
reservation 1 — N reservation_item（一行=一间住 N 晚）
room_type 1 — N reservation_item（被预订的房型）
room 1 — N reservation_item（排房后分配，可空）
reservation 1 — N payment（支付/退款流水）
user / room_type 1 — N review（迭代）
